# CNT / LiPF6-in-carbonate electrolyte MD reference set

Four classical-MD reference systems for the lift/classifier stage:
LiPF6 in a 1:1 (by volume) EC:EMC carbonate solvent inside armchair
carbon nanotubes, with the axial electric field off/on. Generated by an
independent MD engine with published potentials (house rule: generator
code never imports `chaord`).

## Physics (see `params.py` for full provenance text)

- Potential: OPLS-AA-based rigid molecules, LJ + point charges;
  Lorentz-Berthelot mixing (recorded deviation from strict OPLS geometric
  sigma); LJ/Coulomb cutoff 12 A; PPPM (rel. acc 1e-4).
  Parameters from Nutakki 2023 (UIC thesis, Tables II-III; local copy
  `_lit/nutakki2023.pdf`, values re-verified against the PDF), OPLS-AA
  (Jorgensen 1996) for the EMC alkyl tail, Werder 2003 sp2-C LJ for the
  CNT, Saito 1998 for the tube geometry. Joung-Cheatham 2008 Li+ recorded
  as an unused alternative.
- Rigid molecules: `fix rigid/nvt/small molecule` for multi-atom bodies,
  `fix nvt` for Li+ (single-particle rigid bodies are rejected by LAMMPS);
  Nose-Hoover, Tdamp 100 fs.
- Tube atoms frozen (`fix setforce 0`), q = 0.
- Protocol per system (identical except seeds and field): dt 1 fs;
  50 ps ramp 10 -> 300 K (field already on for field1); 400 ps NVT
  equilibration at 300 K; 100 ps production; dump every 5 ps
  (21 frames, `id mol type q x y z`, unscaled, with box bounds).
- Engine: LAMMPS 22 Jul 2025 Update 4, serial, Windows
  (`C:\ProgramData\anaconda3\Scripts\lmp.exe`).

## Sanity checks (full numbers in `runs/<system>/sanity_*.json`)

All four systems, all 21 production frames:
- atom count constant, no atom outside the tube (max mobile radius
  4.57/8.69 A vs tube radii 6.78/10.85 A), composition frame-stable;
- min intermolecular heavy-atom distance 2.52-2.67 A;
  worst 0.75x-Bondi ratio 1.10-1.18 (PASS; floor per the repo's molecular
  dialect: 0.75 x Bondi sum on heavy-atom pairs, cation pairs exempt);
- 0.8 x mixed-sigma LJ floor PASS;
- in-tube density (vdW pore): 1.2805 g/cm3 (cnt10) and 1.2241 (cnt16)
  vs 1.17 bulk EC:EMC 1:1 (+9.4% / +4.6%; confinement-compressed);
- equilibration evidence: Tmob 299-303 K (correct-DOF mobile temperature
  v_Tmob; the raw LAMMPS `temp` column is diluted by the frozen tube
  atoms); PE quarter-means settle during the 400 ps stage
  (|q4-q1| <= 3.2 kT/molecule, last-half slopes <= 0.23 kcal/mol/ps).

## File map

    params.py            all physical parameters + literature citations
    build_systems.py     molecule templates + CNT builder + pack-then-relax
                         packer -> data/<system>.data (+ build_manifest.json)
    write_inputs.py      generates in.<system> (LAMMPS run inputs)
    sanity_checks.py     dump-based post-MD sanity checks
    analyze_equil.py     equilibration evidence from log.lammps
    make_provenance.py   consolidates provenance_<system>.json
    data/                <system>.data, build_manifest.json
    runs/<system>/       prod.dump (21 frames), equil.dump (17 frames),
                         final.data, log.lammps, screen.log,
                         sanity_*.json, equil_*.json, provenance_*.json
    _lit/                downloaded literature (thesis PDF, JC2008 XML,
                         field-effect ESI, Sandia EC/PC force-field paper)

Regenerate everything deterministically:
`python build_systems.py && python write_inputs.py`, then per system
`cd runs/<system> && lmp -in ../../in.<system> > screen.log 2>&1`, then
`python sanity_checks.py && python analyze_equil.py && python make_provenance.py`.

The production dump for the lift/classifier stage is
`runs/<system>/prod.dump` (columns `id mol type q x y z`, unscaled;
`ITEM: BOX BOUNDS` present; 21 frames at 0, 5, ..., 100 ps).

## Honest deviations and fixes made while resuming this work package
(2026-10-14; full list in each provenance JSON)

The previous agent left parameter/build/input scripts and three data
files, but had run nothing. Executing the plan surfaced and fixed:
1. EMC template geometry: the z-matrix builder put the ethoxy OS 0.68 A
   from the carbonyl OC (angle convention mismatch; enforced OC-CO-OS =
   143.7/30.6 deg instead of 123.4). Rebuilt as an explicit planar
   construction asserting every Table-III bond/angle/dihedral. This
   invalidated all three pre-existing data files (rigid molecules keep
   the collapsed geometry forever) - all four were rebuilt.
2. Packing: with the corrected (extended) EMC, pure rejection sampling
   jams at ~55-60% of the bulk density, so the documented bulk-density
   compositions are unreachable by rejection alone (the previous
   agent's (16,16) "successes" were an artifact of the collapsed EMC
   footprint). The packer now does pack-then-relax (the repo's W8
   approach): best-of-N tolerant insertion + rigid-body push-apart
   relaxation, verified against the same strict floors; solvent
   insertion order changed to EC-before-EMC. Compositions restored to
   the previous agent's documented targets (8/5/2 and 37/24/6) and the
   original build seeds (20261001-20261004) work again.
3. Li+ integration: both rigid fix styles reject single-particle
   bodies -> Li+ atoms carry their own Nose-Hoover `fix nvt` (same
   targets/damping). Found on first execution.
4. Velocity ramp consistency: velocities now created at 10 K to match
   the documented 10 -> 300 K ramp (was: 300 K create + 10 K ramp
   start = quench-then-reheat).
5. Diagnostics: thermo displays v_Tmob = 2KE/(DOF*kB) of the mobile
   subsystem with correct rigid-body DOF (the default temperature is
   diluted by the frozen zero-velocity tube atoms); equilibration dump
   every 25 ps added for the density-plateau record.
6. Known-benign LAMMPS warning kept: neighbour exclusions + kspace
   (real-space intra-body pairs excluded; the reciprocal-space
   intra-body term is a constant energy offset with zero net
   force/torque on rigid bodies).
